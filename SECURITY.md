# Security policy

## Supported versions

Security fixes target the latest stable release. Reports about the current source on `main` are also welcome. [RDCM releases](https://github.com/behnamfaghih/RDCM/releases)

## Report a security vulnerability

To contact the maintainer privately, open the repository’s advisories page and select **Report a vulnerability**. Keep vulnerability reports out of public issues and pull requests. [RDCM advisories](https://github.com/behnamfaghih/RDCM/security/advisories)

Include your RDCM and Windows versions, the affected feature, the potential impact and any relevant redacted diagnostics. Remove credentials, personal information and live connection details before sharing logs, screenshots or examples.

The maintainer will use the private report to discuss findings, fixes and disclosure timing.
