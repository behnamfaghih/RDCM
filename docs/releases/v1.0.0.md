# RDCM v1.0.0 — Windows installer preview

This is the first public prerelease of RDCM (Remote Connection Manager), a Windows WPF application for organising saved Remote Desktop connection profiles and opening sessions in tabs.

> **Preview / not production-validated.** The MSI attached to this GitHub Release is built by the repository's Windows GitHub Actions workflow. It must pass a Release build, the RDCM automated checks, an MSI install/uninstall smoke test and an SHA-256 checksum check before the workflow can publish it. These checks do **not** replace the manual real-RDP, mixed-DPI, upgrade, downgrade and rollback tests required by the [release checklist](../../README.md#releasing). This MSI is not code-signed.

## What is included

- **`RDCM-1.0.0-win-x64.msi`** — framework-dependent, per-user Windows installer built in CI. Installation does not require administrator rights.
- **`RDCM-1.0.0-win-x64.msi.sha256`** — SHA-256 integrity checksum of the **CI-built** MSI.
- **Source code** — automatically generated GitHub archives under the MIT License.

The uploaded MSI and WiX debug files provided directly to the maintainer are **not** used as the GitHub Release assets. The published MSI is built from the repository's checked-in source; its hash is therefore not assumed to match a locally built MSI.

## Requirements

- Windows 10 or 11, 64-bit, with the built-in Windows Remote Desktop ActiveX component.
- .NET 10 Desktop Runtime (x64): https://dotnet.microsoft.com/download/dotnet/10.0
- A remote Windows computer that accepts RDP connections to use session functionality.

Uninstalling RDCM should not delete stored connection profiles and settings under `%LOCALAPPDATA%\RDCM`. RDCM does not save passwords.

## Verify the MSI checksum

Download the MSI and its corresponding `.sha256` file from **this exact GitHub Release** into the same folder. Run in PowerShell:

```powershell
Get-FileHash .\RDCM-1.0.0-win-x64.msi -Algorithm SHA256
Get-Content .\RDCM-1.0.0-win-x64.msi.sha256
```

The two hexadecimal hashes should match. A matching checksum detects unexpected file changes; it does **not** prove publisher identity or provide an Authenticode signature.

## Highlights

- Tabbed RDP sessions hosted by Windows' Remote Desktop ActiveX control rather than separate `mstsc.exe` windows.
- Connection search, favourites, recents, command palette and light/dark appearance.
- Per-monitor DPI awareness and live session display resizing.
- Session reconnect, useful error reporting, and resilient local profile persistence.
- Local automated test runner and WiX per-user installer.

## Known release limitations

This is an early public project, and the preview installer is **not** claimed to be fully validated for production. Before promoting this prerelease to a stable release, manually test fresh install, update/upgrade, rollback, uninstall/reinstall, local data preservation and an actual RDP session, preferably across monitors with different DPI settings. Windows SmartScreen may warn about this unsigned installer.
