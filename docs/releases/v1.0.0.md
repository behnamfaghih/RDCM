# RDCM v1.0.0 — first public source preview

This is the first public, versioned source-code preview of RDCM (Remote Connection Manager), a Windows WPF application for managing saved Remote Desktop connection profiles and opening sessions in tabs inside the application.

## Highlights

- Tabbed RDP sessions hosted by the built-in Windows Remote Desktop control rather than separate `mstsc.exe` windows.
- Searchable connection profiles, favourites, recents, command palette, light and dark modes.
- Credentials are never saved by RDCM; per-user connection profiles and settings survive installer removal.
- Per-monitor DPI awareness, dynamic RDP display resizing, reconnect handling and error diagnostics.
- A per-user Windows MSI installer project and a local automated test runner are included in the source.

## Download and build

**This public preview is source-only. No MSI installer is attached to this GitHub Release.** Use GitHub's automatically generated source archives, or clone the repository. On Windows 10/11 (x64) with the .NET 10 SDK, build with:

```powershell
dotnet build .\RDCM.sln -c Release
dotnet run --project .\RDCM.Tests\RDCM.Tests.csproj -c Release
dotnet build .\installer\RDCM.Installer.wixproj -c Release
```

The MSI, when built locally, is at `installer\bin\x64\Release\RDCM-1.0.0-win-x64.msi` and requires the .NET 10 Desktop Runtime to install.

A GitHub Actions Windows build stages a candidate MSI and a SHA-256 checksum as workflow artifacts. These are **test candidates, not publicly released installer downloads**.

## Validation and limitations

This source snapshot does not claim that its MSI has passed an independent clean install, upgrade, rollback, uninstall and live RDP test on an appropriate Windows machine. The existing [release checklist](../../README.md#releasing) requires those checks before an installer is published. Unsigned MSI builds can trigger Windows SmartScreen warnings.
