# RDCM v1.0.0 — Stable release

RDCM (Remote Connection Manager) is a Windows WPF application for organising saved Remote Desktop connection profiles and opening sessions in tabs without launching separate `mstsc.exe` windows.

## Download

- **`RDCM-1.0.0-win-x64.msi`** — per-user, framework-dependent Windows x64 installer; no administrator rights required.
- **`RDCM-1.0.0-win-x64.msi.sha256`** — SHA-256 checksum for the installer.
- **Source code** — GitHub-generated archives, under the MIT License.

## Requirements

- Windows 10 or 11, 64-bit, including the Windows Remote Desktop ActiveX component.
- [.NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0).
- An RDP-enabled remote Windows machine for establishing remote sessions.

Installation is for the current Windows user and does not modify firewall rules or security policies. Connection profiles and settings are stored under `%LOCALAPPDATA%\RDCM` and are not intended to be deleted during uninstall. RDCM does not store passwords.

## Verify the download

Download both release assets into the same folder and run:

```powershell
Get-FileHash .\RDCM-1.0.0-win-x64.msi -Algorithm SHA256
Get-Content .\RDCM-1.0.0-win-x64.msi.sha256
```

Confirm that the displayed hexadecimal hashes match. **A checksum verifies file integrity, not publisher identity.**

## Highlights

- Tabbed RDP sessions powered by the built-in Windows Remote Desktop control.
- Profile search, favourites, recents, command palette, and light/dark appearance.
- Per-monitor DPI awareness and live session display resizing.
- Session reconnection, diagnostics and resilient local profile persistence.
- A per-user WiX installer and automated checks.

## Important limitations

**The MSI is unsigned.** Windows SmartScreen may warn when opening it. Users should download it only from a source they trust and verify the checksum.
